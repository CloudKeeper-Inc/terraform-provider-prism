# prism_org_policy (Resource)

Manages an AWS Organizations policy (SCP, tag policy, backup policy, etc.) through CloudKeeper Prism.

The management account is automatically resolved from your Prism customer configuration — no need to specify it.

## Example Usage

```terraform
# Service Control Policy (SCP)
resource "prism_org_policy" "deny_s3" {
  name        = "DenyS3Access"
  description = "Deny all S3 operations"
  policy_type = "SERVICE_CONTROL_POLICY"
  content = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect   = "Deny"
      Action   = "s3:*"
      Resource = "*"
    }]
  })

  tags = {
    Environment = "production"
    ManagedBy   = "terraform"
  }
}

# Resource Control Policy (RCP)
resource "prism_org_policy" "rcp_deny_external_s3" {
  name        = "DenyExternalS3Access"
  description = "Deny S3 access from outside the organization"
  policy_type = "RESOURCE_CONTROL_POLICY"
  content = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect    = "Deny"
      Principal = "*"
      Action    = "s3:*"
      Resource  = "*"
      Condition = {
        StringNotEquals = {
          "aws:PrincipalOrgID" = "o-exampleorgid"
        }
      }
    }]
  })
}

# Tag Policy
resource "prism_org_policy" "require_environment_tag" {
  name        = "RequireEnvironmentTag"
  description = "Enforce Environment tag values"
  policy_type = "TAG_POLICY"
  content = jsonencode({
    tags = {
      Environment = {
        tag_key = {
          "@@assign" = "Environment"
        }
        tag_value = {
          "@@assign" = ["production", "staging", "development"]
        }
      }
    }
  })
}

# Backup Policy
resource "prism_org_policy" "daily_backup" {
  name        = "DailyBackupPolicy"
  description = "Daily backup plan for tagged resources"
  policy_type = "BACKUP_POLICY"
  content = jsonencode({
    plans = {}
  })
}

# AI Services Opt-Out Policy
resource "prism_org_policy" "ai_optout" {
  name        = "AIServicesOptOut"
  description = "Opt out of all AI service data usage"
  policy_type = "AISERVICES_OPT_OUT_POLICY"
  content = jsonencode({
    services = {
      default = {
        opt_out_policy = {
          "@@assign" = "optOut"
        }
      }
    }
  })
}
```

## Schema

### Required

- `content` (String) The policy content as a JSON string
- `name` (String) The friendly name of the policy

### Optional

- `description` (String) A description of the policy
- `policy_type` (String) The type of policy. Valid values: `SERVICE_CONTROL_POLICY`, `TAG_POLICY`, `BACKUP_POLICY`, `AISERVICES_OPT_OUT_POLICY`, `RESOURCE_CONTROL_POLICY`. Defaults to `SERVICE_CONTROL_POLICY`. Changing this forces a new resource to be created.
- `tags` (Map of String) Key-value tags to attach to the policy

### Read-Only

- `aws_managed` (Boolean) Whether the policy is an AWS-managed policy
- `id` (String) The unique identifier of the policy

## Import

Import is supported using the following syntax:

```shell
# Org policies are imported by their policy ID.
# The management account is resolved automatically, so it is not part of the ID.
terraform import prism_org_policy.example "p-examplepolicyid"
```
