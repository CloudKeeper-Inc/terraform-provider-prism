# prism_org_ou (Resource)

Manages an AWS Organizations organizational unit (OU) through CloudKeeper Prism. Optionally manages which accounts are placed in the OU.

The management account is automatically resolved from your Prism customer configuration — no need to specify it.

## Example Usage

```terraform
# Create an OU under the organization root
resource "prism_org_ou" "production" {
  name      = "Production"
  parent_id = "ou-xxxx-xxxxxxxx" # Root or parent OU ID (visible in Accounts > Hierarchy view)

  accounts = [
    "111111111111",
    "222222222222",
  ]
}

# Create a nested OU
resource "prism_org_ou" "prod_data_team" {
  name      = "Data-Team"
  parent_id = prism_org_ou.production.id

  accounts = [
    "333333333333",
  ]
}

# OU without accounts (just organizational structure)
resource "prism_org_ou" "staging" {
  name      = "Staging"
  parent_id = "ou-xxxx-xxxxxxxx"
}
```

## Schema

### Required

- `name` (String) The name of the organizational unit. Changing this forces a new resource to be created.
- `parent_id` (String) The ID of the parent node. Use the root ID (e.g., `r-xxxx`) or another OU ID (e.g., `ou-xxxx-xxxxxxxx`). You can find these IDs in the **Accounts > Hierarchy** view in Prism. Changing this forces a new resource to be created.

### Optional

- `accounts` (Set of String) AWS account IDs to place in this OU. When accounts are added, they are moved into the OU. When removed, they are moved back to the parent. On destroy, all accounts are moved back to the parent before the OU is deleted.

### Read-Only

- `id` (String) The unique identifier of the OU (e.g., `ou-xxxx-xxxxxxxx`).

## Behavior

- **Create**: Creates the OU under the specified parent, then moves any listed accounts into it.
- **Read**: Walks the organization tree to find the OU and its child accounts.
- **Update**: Only the `accounts` attribute can be updated in-place. Accounts added to the set are moved into the OU; accounts removed are moved back to the parent. Changing `name` or `parent_id` forces replacement.
- **Delete**: Moves all managed accounts back to the parent OU, then deletes the OU. The OU must have no child OUs — delete nested OUs first.

## Import

Import is supported using the following syntax:

```shell
# Organizational units are imported by their OU ID.
terraform import prism_org_ou.example ou-xxxx-xxxxxxxx
```

After import, the `accounts` attribute will be populated with the OU's current child accounts on the next `terraform plan`.
